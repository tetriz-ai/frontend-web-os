# Prove every requirement

A synthetic reading-list fixture at acceptance, with three requirements in `docs/app/spec.md`, sample JUnit and a matching synthetic run record generated by `pnpm fixtures`. It demonstrates the checker; these files do not claim a real test execution. One requirement has a passing test tagged with its id, one has a failing test, and one has no test at all. `tests/traceability` passes only the first, quoting the failure for the second.

```sh
examples/prove-every-requirement/run.sh
```

```text
PASS  state/schema
OFF   design-system/schema  no design-system/design-system.json yet; the design-system step writes it
FAIL  tests/traceability    2 findings
      AC-list-2: failing (expected the link under Read, found it under Unread)
      AC-list-3: no test ran (tag a test @AC-list-3)

1 pass, 1 fail, 1 off  NOT VERIFIED
exit code: 1
```
