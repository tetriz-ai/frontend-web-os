# Voice

How the app talks. Optional: fill it in and the copy lens reviews every message against it.

## Banned phrases

- "Oops"
- "Something went wrong" (say what went wrong)
- "Please try again later" (say when, or what to do now)

## Error messages

Say what happened, why, and what to do next:

> Couldn't save the link. The address doesn't start with http:// or https://. Check it and save again.

## Tone

Plain, short, specific. Use the words the user used in the brief.
