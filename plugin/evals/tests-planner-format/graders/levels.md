The plan covers every AC with at least one case, each case names its AC, a level (unit, component, browser-component, e2e or manual) chosen by the cheapest-level rule (the reload case is e2e, the zero-state render is a component test), a platform and a status (new or existing). It includes the six default rows (TC-default-crawl, a11y, keyboard, themes, phone, prod). It never asks for or refers to source code.
